# HOUSEBREAKER — 프로토타입 (MVP v0.1)

확률을 통제해 카지노를 파산시키는 턴제 전략 로그라이크.
`HOUSE_BREAKER_게임_기획서_v0.1.docx` 의 MVP 범위를 웹(HTML/JS)으로 구현한 플레이어블 프로토타입.

## 실행 방법

```bash
node tools/serve.js
```

브라우저에서 http://localhost:8765 접속. (별도 설치·빌드 불필요)

## 조작 방법

1. **베팅**: 칩 단위(5~100 또는 올인)를 고르고 보드의 숫자(스트레이트) 또는 더즌/1:1 베팅 칸을 클릭. 여러 곳 동시 베팅 가능, 같은 곳을 또 누르면 칩이 쌓인다. **우클릭(모바일: 길게 누르기) = 칩 회수**, 보드 하단 현황 바에서 개별 취소·모두 취소.
2. **기술 카드**: 1회용 소모품. 시작 시 0장이며 턴 승리(순수익 발생)마다 1장, 그 외 암시장·이벤트에서 획득. 안 쓴 카드는 다음 전투로 이월된다. 사용 시 포커스도 소비. 자석은 사용 후 보드에서 중심 숫자를 클릭.
3. **스핀**: 가로 숫자 스트립이 감속하며 당첨 숫자가 중앙 포인터에 멈춘다. 리스핀 카드가 없으면 자동 정산.
4. **정산**: 순수익만큼 카지노 금고에 피해. 결과는 팝업으로 표시. 손실은 자금에서 차감. 자금 0 = 파산.
5. **클리어 보상**: 전투 승리 시 패시브(장신구) 3종 중 1택.

딜러는 매 턴 반드시 행동하며, 이번 턴 행동과 다음 턴 예고가 항상 표시되고 턴 시작 팝업으로 공지된다 (기획서 정보 원칙). 맵은 현재 층까지만 상세 공개되고 앞 층은 갈래와 대분류(⚔️ 전투 / 💀 강적 / 👑 보스 / ❓ ???)만 보이며, 층 이동 시 카메라가 현재 위치로 이동한다.

## 구현된 MVP 범위 (기획서 7장 대응)

| 항목 | 기획서 목표 | 구현 |
|---|---|---|
| 캐릭터 | 루비 1명 (룰렛/포커스) | ✅ |
| 기본 시스템 | 룰렛 베팅·결과 생성·포커스 확률 조작 | ✅ |
| 딜러 | 일반 5종 + 엘리트 1 + 보스 1 (마담 루주) | ✅ |
| 기술 | 15개 — 1회용 카드제 (자석, 더블 베팅, 검은 고양이, 제로 아워 등) | ✅ |
| 장신구 | 20개 (깨진 주사위, 붉은 장갑, 마지막 동전 등) | ✅ |
| 계약 | 6개 (하이롤러, 피의 계약, 도박꾼의 혼 등) | ✅ |
| 맵 | 구역 1개 — 일반/하이롤러/암시장/대부업자/라운지/이벤트/금고 노드 | ✅ |
| 이벤트 | 10종 | ✅ |
| 보스 기믹 | 색 봉쇄·당첨 숫자 제거·같은 색 연속 압박·2페이즈 00 추가 | ✅ |
| 완충 장치 | 무료 리스핀(깨진 주사위)·마지막 동전·보험 증서·긴급 대출 | ✅ |

## 파일 구조

- `index.html` — 진입점
- `js/data.js` — 콘텐츠 데이터 (휠, 베팅, 기술, 장신구, 계약, 딜러, 이벤트, 노드)
- `js/game.js` — 게임 로직 + 렌더링 (런 상태, 전투, 맵, 상점, 이벤트)
- `css/style.css` — 다크 카지노 테마
- `tools/serve.js` — 개발용 정적 서버

## 버전 관리

- 현재 버전: **v0.3.0** — [js/version.js](js/version.js)의 `GAME_VERSION` 이 단일 출처이며, 게임 화면 우측 하단 배지로 항상 표시된다.
- 릴리스 절차: `js/version.js` 갱신 → 커밋 → 같은 이름의 git 태그(`git tag -a v0.x.y -m "릴리스 메모"`) → `git push --follow-tags origin main`.
