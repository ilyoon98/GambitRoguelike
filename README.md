# HOUSEBREAKER — 프로토타입 (MVP v0.1)

확률을 통제해 카지노를 파산시키는 턴제 전략 로그라이크.
`HOUSE_BREAKER_게임_기획서_v0.1.docx` 의 MVP 범위를 웹(HTML/JS)으로 구현한 플레이어블 프로토타입.

## 실행 방법

```bash
node tools/serve.js
```

브라우저에서 http://localhost:8765 접속. (별도 설치·빌드 불필요)

## 조작 방법

1. **베팅**: 칩 단위를 고르고 보드의 숫자(스트레이트) 또는 외부 베팅 버튼(빨강/검정, 홀/짝, 하이/로우, 더즌)을 클릭. 각 베팅에 적중률과 기대값(EV)이 표시된다.
2. **기술 사용**: 포커스를 소비해 확률을 조작한다. 자석은 사용 후 보드에서 중심 숫자를 클릭.
3. **스핀 → 결과 확인**: 결과 공개 후 리스핀(보유 시) 또는 결과 확정.
4. **정산**: 순수익만큼 카지노 금고에 피해. 손실은 자금에서 차감. 자금 0 = 파산.

딜러의 이번 턴 행동과 다음 턴 예고가 항상 표시된다 (기획서 정보 원칙).

## 파일 구조

- `index.html` — 진입점
- `js/data.js` — 콘텐츠 데이터 (휠, 베팅, 기술, 장신구, 계약, 딜러, 이벤트, 노드)
- `js/game.js` — 게임 로직 + 렌더링 (런 상태, 전투, 맵, 상점, 이벤트)
- `css/style.css` — 다크 카지노 테마
- `tools/serve.js` — 개발용 정적 서버

## 버전 관리

- 현재 버전: **v0.1.0** — [js/version.js](js/version.js)의 `GAME_VERSION` 이 단일 출처이며, 게임 화면 우측 하단 배지로 항상 표시된다.
- 릴리스 절차: `js/version.js` 갱신 → 커밋 → 같은 이름의 git 태그(`git tag -a v0.x.y -m "릴리스 메모"`) → `git push --follow-tags origin main`.
